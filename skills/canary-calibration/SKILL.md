# 金丝雀元验证与自进化

## 家族契约（e2e-suite）

- phase: custom
- after: assert
- before: report
- inputs: 金丝雀语料（`test-suite/canary.md`，首轮由本成员建）、本轮各成员缺陷清单与证据、env 成员交付的桩开关（含可控流源桩）
- outputs: 元指标（种子命中/漏抓矩阵 + 假绿抽样 + 进化记录）、`evolution-log.md` 更新
- idempotent: yes（种子是夹具层注入，轮末撤除并核验）

## 定位

家族没有外部校验者：发现靠 grep、产物链靠 LLM 读、红线靠 LLM 申报——**"走形式"风险在元层，不在单个成员**。本成员用"已知缺陷"反测"抓缺陷的能力"：

- 种子命中 = 家族机制健康；
- 种子漏抓 = **家族**坏了（该抓没抓到），不是被测系统缺陷——触发自进化修家族；
- 命中率的连续变化就是家族的体检表。

## 金丝雀语料（`test-suite/canary.md`）

- **种子只注入在夹具/桩层**（桩服务/可控流源桩的开关：断流点、静默、终端事件关、字段静默丢弃等），**绝不改被测系统代码制造缺陷**；
- 每条种子四要素：编号 / 注入点与开关 / 预期捕获通道（哪个成员、什么证据形态）/ 状态（驻留·每轮常开，标记"种子（预期）"）；
- **语料两个来源**：① 本轮真实缺陷（修复后）中满足"通用性"口径（可复用于同类其他系统、不依赖被测系统产品形态）的 → 种子化（缺陷→防线的闭环；design 类成员排入时以其通用性筛选为准）；② 契约高危区已知模式（假成功/静默降级）；
- 语料属被测系统（存该系统 `test-suite/`），不进技能正文；无可控桩层的系统，语料暂限于只读观测类高危模式（如"某字段不应明文出现"），桩层就绪后扩。

## 元验证（每轮，assert 之后）

1. **对账**：本轮缺陷清单 × 语料 → 命中/漏抓矩阵：
   - 命中且走预期通道 → 种子验证通过；
   - 命中但走非预期通道 → 记录（通道归因修正，供进化参考）；
   - **漏抓 → 触发自进化**；
2. **假绿抽样**：随机抽 ≥3 条本轮"通过"结论，重新取证复核；结论翻转即假绿，计入元指标（假绿率爬升 = 某成员开始走形式）；
3. 输出元指标：种子命中率、假绿样本、漏抓清单、（若有）进化记录。

## 自进化（漏抓时，重试上限 1 次；**提案与应用分离**）

1. **归因**：按种子的"预期捕获通道"定位责任成员；
2. **进化提案**（本成员只"提案"，不"写他人定义"）：目标成员追加 ≤1 条缺失的断言/红线条款——**只增、不删改既有条款**，把完整 diff（原→新）+ 回退方法写进进化日志；
3. **应用与重放**：由总控把提案应用到目标成员 SKILL.md（成员之间不互写文件，保持各自独立个体），保持该种子注入，只重放被归因成员，确认抓到；
4. **仍漏抓 → 停止并升级给用户**（不循环进化、不放大改动面），提案标"进化挂起 + 疑似原因"；
5. **进化日志**（`test-suite/evolution-log.md`）：日期、种子号、目标成员、条款 diff（原→新）、应用状态（总控已应用/用户否决已回退）、重放结果、回退方法（恢复原文的完整内容）。

## 红线

- **种子与缺陷分轨**：种子命中在报告标"种子（预期）"，不计入被测系统真实缺陷统计；
- 轮末撤除全部种子（开关关闭）、还原桩，还原核验作为收尾验收项；
- 本成员只产出进化提案（diff+回退法记日志），**写成员 SKILL.md 由总控执行**（成员互不写文件，保持独立个体）；夹具层注入对象是桩开关；用户否决进化 = 按进化日志回退，本轮不重试该手术；
- 元指标必须带判断输出：命中率连续 2 轮下降 → 报告明说"家族机制在退化，定位到成员 X"，不只报数字。
