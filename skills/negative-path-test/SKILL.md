# 反例与降级路径测试

## 家族契约（e2e-suite）

- phase: exec
- after: env
- inputs: 上轮反例矩阵（回归基线，可选）、环境说明（隧道/凭据/夹具/备份位置）、接口契约文档、桩服务清单（流式类系统须含**可控流源桩**：断流点/静默时长/终端事件开关，由 env 类成员预置）
- outputs: 反例用例矩阵 + 注入与恢复记录 + 缺陷清单
- idempotent: yes（每次注入后必须还原）

## 定位

正向功能再好，一条未处理的异常路径就能造成断网、丢数据或假成功。本技能系统化地回答三个问题：

1. 后端是否**安全降级**（回退默认/直连/拒绝并提示），而不是崩溃、挂起或假成功；
2. 前端是否**如实呈现**（错误提示/禁用态/离线态），而不是误导用户成功；
3. 异常解除后是否**可恢复**（自动恢复，或恢复步骤明确可控）。

## 反例矩阵（五个维度生成用例）

| 维度 | 注入手段 | 断言要点 |
|---|---|---|
| **依赖死亡** | 停桩服务、防火墙断网、DB 停服、断开外网 | 后端降级到安全默认；前端显示降级态而非成功；不崩不挂 |
| **非法输入** | 超长/类型错/枚举外值/空值/重复值/特殊字符 | 后端校验拒绝且**不落盘**（400+errors）；前端呈现错误而非静默成功 |
| **状态异常** | 服务未初始化/重启中/强杀后半途/配置文件损坏 | 前端引导正确（401→登录、403→注册）；状态机重置符合声明；坏文件回退默认且错误可见 |
| **资源与配额** | 连接满员/配额耗尽/超时/磁盘占满 | 拒绝+明确提示；拖垮整体的行为记为缺陷 |
| **权限反例** | 降权上下文（runas /trustlevel）访问特权操作 | 后端拒绝；前端隐藏/禁用入口而非露出报错 |

每条用例卡片：`前置状态 → 注入动作 → 后端断言 → 前端呈现断言 → 解除注入 → 恢复断言`。

## 注入手段库

- 停/杀桩服务进程；写坏配置文件（截断/带 BOM/非法类型）；防火墙规则断网；降权上下文执行；改系统时钟（验证冷却/过期内的时间敏感逻辑）；资源占满（临时大文件/连接占位）。
- **主动注入前先布防崩溃转储**（Windows: WER LocalDumps；Linux: coredump），崩溃拿 dump 不猜根因。
- 注入要可精确解除：记录每条注入的还原命令，逐条撤销。

## 断言纪律

- 与 blackbox-e2e-test 同口径：**UI 表象 ≠ 功能生效**，每个断言有后端证据（状态端点/日志/DB/文件）。
- 特别关注"假成功"：注入状态下前端仍报成功 = 高危缺陷。
- **恢复断言**必做：解除注入后系统回到正常态的时间与方式（自动/人工），恢复不了的记缺陷。
- 注入引起的用户数据变化必须还原（备份先行）。
